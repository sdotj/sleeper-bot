# Design: figma-ui-replica

## Approach
Reuse the existing React, Tailwind tokens and UI primitives, following dec.gui-architecture, dec.chat-history-memory and dec.ui-config-editing. Host the exact exported status asset and Inter fonts locally. Keep account actions accessible from the avatar.

MODIFIED: Shared shell, cards, tables, feature layouts and scroll tracking.
ADDED: Local design assets and focused navigation tests.
REMOVED: Duplicate section headings and decorative card blur.
